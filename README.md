# Revit 2026 專案模型範例 (Revit MCP Study)

此倉庫由 **Antigravity AI Agent** 配合 **Revit MCP** 自動建立。

## 📦 檔案清單

- `Sample_Project_2026.rvt`：Autodesk Revit 2026 專案模型檔（繁體中文公制範本）。

## 🏗️ 剛才在 Revit 即時建立的模型構件

透過 `revit-mcp` 工具直接在 Revit 即時生成了以下構件：

1. **4 面外牆 (Walls)**：10m × 8m 矩形建築平面，牆高 3600 mm。
2. **1 塊樓板 (Floor)**：鋪設於 L1 樓層（0,0 至 10000, 8000）。
3. **1 扇門 (Door)**：放置於南側外牆中央（ElementId: 1240492）。
4. **2 扇窗 (Windows)**：放置於北側外牆（ElementId: 1240494 與 1240508）。

## 🚀 如何使用

1. 以 **Autodesk Revit 2026** 開啟本倉庫中的 `Sample_Project_2026.rvt`。
2. 啟動 `RevitMCP` 附加元件，即可透過 AI 自然語言進行自動化建模與查詢。
